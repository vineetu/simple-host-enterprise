What Simple Host does

Simple Host gives internal websites a stable place to live, change, and be shared.

Publish a website

An assistant can publish a folder, a prototype, or an idea as a website. The site can also include files that people can download.

Update it or go back

Each update becomes a new version. Simple Host keeps the five most recent versions, so the owner can return to an earlier one when needed.

Work on one site together

Publish a site under a team, and every member can update it. Everyone works on the same site at the team's URL, with one shared version history.

Save shared information

Trackers, Gantt charts, and similar sites can save information that is shared by their visitors. Anyone who can open the site can change it, so it must never contain passwords, personal information, or other secrets. The last 20 versions are kept, so the owner can undo a bad change.

Choose who can open it

A new site opens only for its owner or team. The owner can then share it with named people or teams, with anyone in the company who has the link, or also list it in Showcase and search. Opening it to people without a company sign-in needs an admin's approval.

Check activity

Owners can view site activity over 7 days, 30 days, 6 weeks, or 6 months.

Good to know

  • Uploaded server code is stored but not run.
  • Use the Simple Host skill to build and publish a site.
  • Developers can use the API reference for state, search, collaboration, and integration contracts.

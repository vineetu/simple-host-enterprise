Simple Host Enterprise is installed but not started: it needs a domain, your
company's sign-in and a bucket first.
{{- if eq .Values.postgres.mode "incluster" }} The database is running.{{ end }}

Set host, oidc.issuer, oidc.clientId, oidc.clientSecret, oidc.adminEmails,
storage.bucket, storage.accessKeyId, storage.secretAccessKey,
certificates.acme.email and certificates.acme.digitaloceanToken in a values
file, then:

  helm upgrade {{ .Release.Name }} oci://ghcr.io/vineetu/charts/simple-host-enterprise -n {{ .Release.Namespace }} --reuse-values -f my-values.yaml

Guide: https://github.com/vineetu/simple-host-enterprise/blob/main/docs/cloud/digitalocean.md
{{- else }}
Simple Host Enterprise is starting at https://{{ .Values.host }}

1. Point {{ .Values.host }} and *.{{ .Values.host }} at the ingress load balancer:
     kubectl get svc -A -l app.kubernetes.io/name=ingress-nginx
2. Register https://{{ .Values.host }}/auth/callback as the redirect URI at your identity provider.
3. Watch it come up:
     kubectl -n {{ .Release.Namespace }} rollout status deploy/simple-host
{{- if not .Values.secrets.existingSecret }}
{{- if ne .Values.storage.envelopeKey "-" }}

Back up the envelope key now. Every site in the bucket is unreadable without it:
  kubectl -n {{ .Release.Namespace }} get secret simple-host-secrets -o jsonpath='{.data.BACKUP_ENVELOPE_KEY}' | base64 -d > envelope-key.txt
{{- end }}
{{- end }}
{{- if eq .Values.postgres.mode "incluster" }}

The database runs in the cluster and nothing backs it up. For real use, move
to a managed database (postgres.mode=external).
